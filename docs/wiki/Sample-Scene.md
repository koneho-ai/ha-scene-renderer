# Sample Scene

The add-on ships with a bundled sample apartment (`scene-renderer/models/sample-apartment.glb`, the default `model` option) so the integration works out of the box. It is generated by `scripts/generate_sample_model.py` — pure Python, no dependencies — re-run it to regenerate the file.

## Layout

A small, clean, dollhouse-style apartment, 12 × 8 metres, walls 2.6 m high, glTF Y-up. There is **no ceiling**, so the overview camera sees inside.

```
+-----------+-----------+
|           |           |
|  Living   |  Kitchen  |
|  0-7,0-5  |  7-12,0-5 |
+-----------+-----------+
|           |           |
|  Bedroom  | Bathroom  |
|  0-7,5-8  |  7-12,5-8 |
+-----------+-----------+
```

Simple box furniture in every room: living room with sofa, coffee table, rug, TV, bookshelf and a floor lamp; kitchen with counter, fridge, dining table and four chairs; bedroom with bed, wardrobe and nightstand; bathroom with tub, vanity, sink, mirror and toilet. Interior walls have door gaps with lintels.

## The 2 named cameras

| Name | Position (m) | Target (m) | Vertical FOV | Framing |
| --- | --- | --- | --- | --- |
| `overview` | (15, 12, 13) | (6, 0.8, 4) | 45° | Isometric dollhouse view of the whole apartment |
| `living_room` | (6.2, 2.0, 4.4) | (1.8, 0.6, 1.6) | 55° | Inside the living room, looking at the sofa and coffee table |

Each camera is its own image entity in Home Assistant (e.g. `image.scene_renderer_overview`).

## The ceiling fan

A group node named `ceiling_fan` hangs in the living room (hub + 4 blades as children; the downrod is static, not part of the group). It has a glTF rotation animation, `ceiling_fan_spin`, of **one full turn per 3 s** — keyframed in 90° steps at 0, 0.75, 1.5, 2.25 and 3.0 s (a 360° turn cannot be keyframed with start/end alone, since slerp between identical orientations takes the zero-length path). 3 s matches the default clip duration, so a 3 s clip loops seamlessly. The bundled `scene.example.js` also spins the fan from the script, which overrides the model's animation — delete that block to let the built-in animation do it.

## The blinds

A group node named `blinds` hangs over the living-room window (north wall). Group nodes carry real transforms, so the scene API can move them — unlike furniture boxes, whose position is baked into the geometry. The bundled `scene.example.js` moves the blinds up and down with the sun elevation. See [[Scene Scripting]].
